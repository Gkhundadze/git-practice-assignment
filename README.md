# დავალება: პერსონალური სავიზიტო ბარათი (Git & GitHub)

დავალების მთავარი მიზანია Git-ის საბაზისო პრინციპების პრაქტიკაში გამოყენება: ლოკალური ცვლილებების ეტაპობრივი დაფიქსირება, რეპოზიტორიის გამართვა, დოკუმენტაცია და პროექტის გაშვება (deploy).

## რას ვაკეთებთ

უნდა ააწყოთ მარტივი, ერთგვერდიანი სავიზიტო ბარათი (HTML/CSS):

* პროფილის ფოტო ან ავატარი

* სახელი, გვარი და პოზიცია / მიმართულება

* მოკლე აღწერა თქვენ შესახებ (2-3 წინადადება)

* მინიმუმ 2-3 სოციალური ქსელის აქტიური ბმული

* საბაზისო სტილები: ელემენტების ცენტრირება, ფერები, ჰოვერ-ეფექტები ღილაკებზე

## ტექნიკური მოთხოვნები (Git & GitHub)

სამუშაო პროცესში შეგიძლიათ გამოიყენოთ როგორც ტერმინალი, ისე GitHub Desktop — არჩევანი თქვენზეა.

1. **რეპოზიტორია:** შექმენით ახალი საჯარო (Public) რეპოზიტორია სახელით `personal-bio-card`.

2. **კომიტები:** პროექტი არ უნდა აიტვირთოს ერთიანად. აუცილებელია მინიმუმ 3-4 ლოგიკური კომიტი (მაგალითად: საწყისი მარკაპი, სტილების დამატება, README-ის გამართვა). კომიტის მესიჯები დაწერეთ ინგლისურად, მოკლედ და კონკრეტულად.

3. **დოკუმენტაცია:** პროექტის დირექტორიაში შექმენით `README.md` ფაილი.

4. **Deploy:** გაუშვით საიტი GitHub Pages-ზე, რათა ვიზუალი პირდაპირ ბრაუზერში იხსნებოდეს.

## README.md ფაილის შაბლონი

თქვენს რეპოზიტორიაში არსებულ `README.md`-ში ჩასვით და შეავსეთ შემდეგი ინფორმაცია:

```
# Personal Bio Card

პროექტის მოკლე აღწერა (1-2 წინადადება).

## Live Demo
აქ ჩასვით GitHub Pages-ის ბმული

## გამოყენებული ტექნოლოგიები
* HTML5
* CSS3
* Git & GitHub

## ლოკალურად გაშვება
1. პროექტის კლონირება:
   git clone [თქვენი-რეპოზიტორიის-ლინკი]
2. გახსენით index.html ბრაუზერში.

## ავტორი
* სახელი და გვარი
* GitHub: @თქვენი-username

```

## ჩაბარების წესი

დავალებაში აგზავნით მხოლოდ GitHub რეპოზიტორიის ბმულს.

გადამოწმდება:

* არის თუ არა რეპოზიტორია Public;

* კომიტების რაოდენობა და შინაარსი;

* README.md ფაილის სისრულე;

* GitHub Pages-ის მომუშავე ბმული (რომელიც README-შივე უნდა ეწეროს).
